## About

This repo holds my solutions to the NeetCode 150 problem set, worked through as part of my DSA prep for SDE internship and campus placement. Problems are solved topic by topic, following the standard progression: arrays, two pointers, sliding window, hashing, stacks, linked lists, trees, BFS/DFS, binary search, heaps, graphs, backtracking, DP, and tries.

Each solution reflects my own attempt first, then a revisit for cleaner or more optimal approaches where relevant (e.g. brute force → optimized, or adding a two-pointer/sliding-window pass after an initial hashmap solution).

---

## Repository structure

Solutions are organized by topic, then by problem, in kebab-case:

```
<topic>/
  <problem-name>/
    solution.<ext>
```

**Example:**
```
arrays-hashing/valid-anagram/solution.py
sliding-window/longest-substring-without-repeating/solution.py
two-pointers/valid-palindrome/solution.java
```
